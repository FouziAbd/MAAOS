# Domain `cooperative_grid`

Generated by `python -m maaos create-domain cooperative_grid`. Guide: `docs/domains/ADDING_A_DOMAIN.md`.

| File | Role | You edit |
|---|---|---|
| `types.py` | value types: `State`, `Call`, `Task` (+ `identities()`) | the objects, actions and goal of your domain |
| `model.py` | the optimistic symbolic model: `project`, `apply`, `applicable`, `plan` (no `apply_world`: a place is a region, so the world effect of a `Goto` is not predictable cell by cell) | the intended effects and preconditions |
| `environment.py` | the backend boundary: `_reset`, `_attempt`, `_is_terminal` | how actions really execute (the only module that may import a backend) |
| `__init__.py` | the declaration `DOMAIN` (tasks, examples, recovery advice) | tasks, examples, recovery |

Check it: `python -m maaos validate-domain cooperative_grid` (after adding the registry lines it prints).
Run the generated test: `python -B -m unittest tests.test_domain_cooperative_grid`.

Run an episode yourself:

```python
from app.assembly import assemble_loop
from shared.orchestration_config import OrchestrationConfig, OrchestrationPolicy
from domains.cooperative_grid import DOMAIN
episode = assemble_loop(DOMAIN, config=OrchestrationConfig(policy=OrchestrationPolicy.ADVISORY_TWO_TRACK)).run()
print(episode.outcome, [str(e.selected_call) for e in episode.history.entries])
```
